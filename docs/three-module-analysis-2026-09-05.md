# 三模块实验分析与架构图修订依据

日期：2026-09-05。

分析依据为本地代码、`tools/owod/README.md`、`run_stage1_retention_pilot.sh`、上传架构图和原始改图 prompt。本地 `exps`、`log` 下未找到可供分析的实验指标文件，因此本文评价实现机制和实验设计，不声称某项修改已提高 mAP。没有修改模型代码或重新训练。

## 1. 结论

保留三个模块合理：GNN 估计旧类别受干扰风险，持续学习目标把风险转成回放分配和约束，LoRA 执行参数更新。最值得优先改进的是风险信号的可信度、保护子空间的覆盖率和实验对照的公平性。直接扩大 GNN 或增加第四模块，目前缺乏依据。

配套改图 prompt 以仓库中的 retention-aware pilot 为具体配置依据：所有旧类别基础回放 + 高风险类别额外回放，阶段级共享 LoRA，教师补标、局部 margin 和非邻域投影约束。runner 也支持仅邻域回放等其他配置；不能把 pilot 配置当成所有运行的统一行为。实际服务器运行配置仍需以对应 `run_config.json` 和 `graph.json` 为准。

## 2. Class-Interference GNN

### 已实现

- 在阶段训练前，从当前类别训练集和历史旧类别样本提取检测器末两层 Decoder FFN 权重的类别梯度。固定参数状态仍可计算梯度；这不是执行优化器更新。
- 将原始大维度梯度通过一维自适应平均池化压缩，再做 L2 归一化，作为类别节点特征。
- 有向 GNN 使用节点编码、消息传递和有序类别对评分，方向 `u -> c` 表示源类别 u 的适配可能提高目标类别 c 的损失。
- 用已完成阶段训练数据上的短程 LoRA probe，测量目标类别损失增量，监督 GNN。当前检测器训练不会通过总损失更新 GNN。
- 当一个阶段引入多个新类别时，对每个旧类别聚合来自新类别的风险分数，再做阶段级 Top-K。pilot 使用 top-3 mean。

### 优先优化

1. **类别梯度可能混入人为背景冲突。** `target_for_class` 删除同图其他类别标注，然后对筛选后的 target 重新执行完整 criterion。DETR 的分类损失仍作用于全部 queries，所以被删除标注对应的真实目标可能成为负例。GNN 学到的部分干扰可能来自构造方式，而非真实遗忘。建议比较：现方案；完整标注下统一匹配后按目标类别归属分解正样本分类/定位损失；对其他已知前景 query 屏蔽负例项的方案。背景损失怎样分配应明确，不能简单移除全部背景监督。probe 和 harm 测量也要采用一致定义。
2. **平均池化不保证保持梯度几何关系。** 不同层、不同矩阵的梯度坐标被连续平均，正负信号可能抵消；归一化还丢失更新敏感度的尺度。可比较按层归一化后拼接、固定种子的随机投影或 CountSketch，并把 log 梯度范数、样本数作为补充节点特征。先测原始与压缩梯度的内积/余弦保持情况，再决定替换。
3. **风险分数不是校准概率。** 当前监督对每个源类别的正损失增量按行最大值归一化。弱干扰源和强干扰源可能产生相近的归一化分数，跨新类别取 top-mean 会混合不同尺度。建议同时记录绝对/相对损失增量，比较带尺度特征的评分或排序目标，并检查 Top-K recall、NDCG 和跨阶段泛化。图中称为 risk score，不称为 calibrated probability。
4. **小样本 probe 的代表性。** 当前类别样本取固定顺序的前若干张；可改为可复现的分层/随机多子集采样，并对 probe 使用多个种子及独立训练子集评估 harm。未测边继续使用 mask，不能当成零风险。

代码依据：`tools/owod/gnn_calibration.py:71,90,124,230,271`；`models/graph_local/gnn.py:26,192`；`tools/owod/run_graph_local_increment.py:137,199`。

## 3. Neighbor-Scoped LoRA Adapter

### 已实现

- 最后两个 Decoder 层各自的 linear1、linear2，共四个线性投影具有独立 LoRA 因子。
- 一个增量阶段共用一组适配参数；不是每个类别一个 adapter，也没有依据邻域进行前向路由。
- 原检测器参数冻结，仅更新 LoRA 因子和当前新类别的分类器行；旧分类器行和 box head 冻结。
- 分类头参数组关闭 weight decay，避免旧行虽然梯度为零仍被 AdamW 衰减。这一点已经处理，不需要重复列为待修问题。
- 训练后把低秩增量合并回基础权重，移除临时 LoRA；推理不保留 adapter bank。

### 优先优化

1. **澄清“邻域限定”的含义。** LoRA 改变共享特征，可能影响全部类别。“Neighbor-Scoped”在这里指训练目标受邻域约束，不代表前向更新只作用于邻域。图中添加 `Stage-shared; neighborhood-conditioned training` 即可，无需改成复杂的路由模型。
2. **检查容量和位置是否匹配任务。** 先比较 rank 4/8/16、末一层与末两层、仅 linear2 与两层投影。记录新类 AP、旧类 AP、参数量和训练时间，并对初始化、学习率及训练步数保持一致。没有证据时不扩大可训练范围。
3. **区分子空间约束与输出保持。** FFN 增量受到约束，不等于旧类别预测不变；新分类器行仍可能在旧目标处产生较高分数。需要直接检查旧目标误分类、新类误报、定位变化，而不能只检查旧权重是否冻结。

代码依据：`models/graph_local/lora.py:74,98,216`；`main.py:399` 附近的分类头优化器分组。

## 4. Graph-Conditioned Continual Objective

### 已实现与图中应使用的公式

令阶段 t 的旧类别集合为 K_(t-1)，新类别集合为 U_t，阶段风险邻域为 N_t。

**回放：** pilot 为每个旧类别分配基础 quota b，邻域类别增加 e：

`q_c = b + e * 1[c in N_t], c in K_(t-1)`。

pilot 中 b=10、e=40、K=5、回放采样比例=0.10。这些是工程 pilot 参数，不是已验证的最优超参数或官方复现配方。去重和类别共现会使实际类别曝光与 quota 不完全一致。

**教师补标：** 学生与冻结的上一阶段教师接收同一混合训练 batch。教师为全部旧类别生成候选框，进行置信度、类内去重和 GT 重叠过滤，再补充该 batch 的 targets。因此，补标可以作用于当前图像和回放图像；它不是把两套图像数据简单做集合并集。

**局部 margin：** `C_t = U_t union N_t`。只对 Hungarian 匹配且真实标签属于 C_t 的 queries 计算真实类别与最强局部竞争类别之间的 hinge，最后对这些 queries 取平均；没有有效 query 时为零。

**非邻域保护：** 原始完整 FFN 梯度选择 `K_(t-1) minus N_t`，构造归一化梯度 Gram 矩阵并保留主特征方向，得到 `U_off in R^(D x d_off)`。它不是来自 GNN 压缩后的节点向量。

令 delta 为四个 LoRA 稠密权重增量按与原始梯度相同顺序展平拼接的向量。实际实现为：

`L_off = ||U_off^T delta||_2^2 / d_off`，`d_off=0` 时为零。

原 prompt 写成平方和，少了平均因子。固定秩时可以吸收到系数中，但展示当前实现时应写准确，并把 LoRA rank r 与保护基秩 d_off 区分。

### 优先优化

1. **检查保护基覆盖率。** pilot 将非邻域类别梯度子空间截断到最多 8 维，可能遗漏低能量但重要的类别方向。记录保留特征值能量比例和各类别投影残差，再比较固定秩与能量阈值选秩。不能把有限秩、阶段开始时构造的线性约束描述成“不遗忘保证”。
2. **检查投影惩罚是否过强或过弱。** 对每个损失记录它对 LoRA 的梯度范数、更新投影比例和新旧 AP。当前平方惩罚同时抑制正负方向，可能连改善旧类的更新也被压制；未来可以比较仅惩罚预测损失增加的单侧一阶约束，但必须作为新实验，不能直接画成已有实现。
3. **抑制伪标签错误放大。** 固定阈值和 GT 重叠过滤可能漏掉拥挤场景中的真实旧目标，也可能留下错误旧类标签；局部 margin 又会强化这些标签。可比较按类别校准阈值、置信度加权的检测/局部损失，以及仅 GT 参与 margin 的对照。
4. **保持回放的真实公平性。** Graph-K 与 Random-K 应匹配每类基础/额外 quota、去重后的图像总量、每轮回放曝光和训练步数。Global 对照要重新分配同一额外预算，不能对每个旧类别都给相同 extra 后宣称只比较选邻居策略。

## 5. 推荐实验顺序

1. 固定现有 pilot，记录至少三个种子的 Previous/Current/Known AP、逐类 AP、遗忘量、回放实际曝光及运行时间。
2. 先比较类别梯度定义及 Graph-K、Random-K、同预算 Global，验证 GNN 是否选中了真正容易受损的旧类别。
3. 再扫描 LoRA rank/位置和 off-basis rank/系数；检查保护与学习新类之间的权衡。
4. 最后分别移除教师补标、local margin、off projection。模块级消融与模块内部消融分开报告：去掉 GNN 后应用随机邻域维持其他流程；去掉 LoRA 后只训练分类行属于容量变化明显的对照，应明确说明；去掉整个图条件目标时要同时说明回放策略是否仍受 GNN 控制。

仓库含可选旧类蒸馏实现，但当前 pilot 未启用，配套主图不添加蒸馏分支。

## 6. 开放世界表述边界

三个模块主要解决增量适配与旧类保留。当前未知评分是 `1 - max(sigmoid(logits))`，不是单独学习的未知目标发现机制。低已知置信度也可能来自背景；因此新旧类别 AP 改善不能直接推导出未知检测改善。应结合 U-Recall、UDP、A-OSE、H-Score 与实际后处理评估。

主图建议聚焦 `Graph-local continual adaptation for Deformable DETR`。如需要表示完整 OWOD 输出，可添加一个普通、无外框的后处理注释，注明使用现有 unknown scoring；不要增加第四个创新模块，也不要把 H 称为已经实现解耦的 `Class-Agnostic Query Features`。用 `Decoder Query Features (H)` 更准确。

代码依据：`models/owod_detector.py:27`；`models/deformable_detr.py:399` 附近。

## 7. 原 prompt 必须修订的图意

| 原表述 | 修订 |
| --- | --- |
| 单一新类别 u 控制整个阶段 | 用 U_t 表示本阶段新类别集合，图中 u 为其中一个示例节点；风险聚合后得到 N_t |
| 每类一个 LoRA，或 N 直接进入 LoRA | 一组阶段共享 LoRA；N 进入训练目标，不参与前向路由 |
| i=1,2 表示全部注入位置 | 用层索引 ell 和投影索引 j，共四处 |
| 每步预测到 GNN 的在线闭环 | 区分阶段开始的梯度统计/固定控制与每个 batch 的优化；GNN 不接受 L_total 反传 |
| 常规 criterion 直接输出按类别损失 | 注明 class-conditioned criterion/statistics，不暗示其是默认输出或普通总损失的严格可加分解 |
| 只有邻域回放 | 全旧类基础回放 + 邻域额外回放，并由采样器混入当前数据 |
| 教师图像与当前数据集合并集 | 同一训练图像的 target completion，教师同时接收混合 batch |
| U_off 来自压缩 x_c | U_off 来自完整 g_c，与 delta 同维、同排序 |
| 投影平方和 | 按保护基维数取平均的平方范数 |
| LoRA 输出在 Decoder 外相加 | 用放大引线连接 Decoder 内部 FFN，残差加法发生在每个被替换的线性层内部 |
| 在原框中塞入所有长公式和说明 | 保留原图风格与三模块位置，利用底部空白重新分配空间；只展示关键公式，细节保留在 prompt 中 |
